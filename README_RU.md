
# Мониторинг производительности серверов.

[Read in English](README.md)

Скрипт на Python для анализа и составления отчетов о статистике производительности на нескольких хостах Linux.

Скрипт подключается по SSH, собирает системные метрики и доставляет отформатированный отчет прямо в Telegram-бот.

Этот проект был создан как расширенное решение для задания [Server Performance Stats](https://roadmap.sh/projects/server-stats) от roadmap.sh. В то время как изначальным требованием был локальный bash-скрипт, данный проект реализует масштабируемую оболочку на Python с оповещениями в реальном времени и поддержкой нескольких хостов.

### Собираемые метрики
* Версия ОС
* Время на сервере
* Нагрузка CPU и Load Average
* Оперативная память (ОЗУ: занято / свободно / %)
* Дисковое пространство (занято / свободно / %)
* Время непрерывной работы (Аптайм)
* Количество авторизованных пользователей
* Количество неудачных попыток входа по SSH (за 24ч)
* Статус запущенных Docker-контейнеров
* Top-5 процессов с наибольшей загрузкой ЦП
* Top-5 процессов с самым высоким потреблением памяти

### Требования
* Целевой сервер на базе Linux
* Python 3.7+
* Настроенная конфигурация SSH (`~/.ssh/config`) для подключения к серверам
* Токен бота Telegram 
* Chat ID Telegram

### Инструкция по использованию

#### 1. Клонирование репозитория
```
git clone https://github.com/Whoami-775/Server-Performance-Stats.git
cd Server-Performance-Stats
```

#### 2. Настройка SSH для беспарольного входа
Убедитесь, что ваш публичный ключ скопирован на целевые серверы в файл .ssh/authorized_keys, а в файле  ~/.ssh/config прописаны имена хостов:
```
Host au-main
    HostName 192.168.122.41
    User root
```

#### 3. Подготовка Telegram-бота
Создайте бота через @BotFather и сохраните полученный токен.
Узнайте Chat ID своего профиля в тг через бота @Getmyid_bot.

#### 4. Запуск скрипта
Внешние зависимости pip не требуются (используются встроенные модули Python urllib, json, subprocess).
Передайте токены через переменные окружения и запустите скрипт:
```
export TELEGRAM_BOT_TOKEN="your_bot_token"
export TELEGRAM_CHAT_ID="your_chat_id"
python3 monitor_servers.py
```

#### 5. Настройка автоматического запуска по расписанию (Cron)

Чтобы получать отчеты каждый час, добавьте задачу в планировщик задач cron:
```
crontab -e
```

Добавьте следующий рабочий таск:
```
0 * * * * export TELEGRAM_BOT_TOKEN="your_token" TELEGRAM_CHAT_ID="your_id"; /usr/bin/python3 /path/to/Server-Performance-Stats/monitor_servers.py > /dev/null 2>&1
```

Основано на учебном проекте Server Performance Stats от roadmap.sh.
